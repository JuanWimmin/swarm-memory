# z32 1.1.0 — verified API (README)

z-base-32 encode/decode (the alphabet Pear uses for keys and `pear://` links).

```js
const z32 = require('z32')
const s = z32.encode(stringOrBuffer)   // → string (32-byte key → 52 chars)
const b = z32.decode(s)                // → Buffer; throws if the string is invalid
```

Use: share `z32.encode(base.key)` / `z32.encode(invite)`; parse with `z32.decode(code)` inside try/catch.
For keys specifically prefer `hypercore-id-encoding` (accepts z32, hex and `pear://` links).
Not in README: `z32.isValid`, `z32.encode(buf, 'hex')`.
